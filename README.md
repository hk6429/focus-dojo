# 專注道場 focus-dojo

個人專注力訓練 PWA。純前端、免帳號、資料存 localStorage，可加到手機主畫面離線使用。

## 功能
- **專注計時**：設任務與時長（15/25/45/60 或自訂），計時中一鍵記錄分心原因（手機／雜念／他人／其他）；離開畫面 ≥10 秒回來會問「是分心嗎」，另存不混入；進行中狀態落地 localStorage 可續算；完成後有休息計時（每 4 回 15 分）與漸進建議（±5 分）；放棄入庫但不計分。
- **呼吸熱身**：預設 4 吸 6 吐（不閉氣）、3 分鐘，另有 4-7-8 與方塊呼吸；到時等本輪結束再停。
- **開工前狀態檢測**：舒爾特方格（1→25 計時）、Stroop 色字（40 題一致／不一致各半、注視點 400ms，回報干擾量＝不一致 RT − 一致 RT）。
- **意圖與回顧**：開始前選填「做完的樣子」「最可能的分心→到時我會」；分心時可把念頭停車，結束畫面列出處理；結束後 1–5 星自評＋一句調整。
- **目標**：每日專注分鐘（預設 50）與每週天數（預設 5），首頁顯示今天進度、標題列顯示本週天數。
- **紀錄**：連續天數（完成或 ≥5 分鐘即算）、30 天品質均值、今日／30 天專注分鐘、每 25 分鐘分心率週趨勢（累積 60 分鐘才顯示）、分心原因排行、遊戲進步、最近紀錄；JSON 匯出／匯入。

- **遊戲化層（八角框架）**：段位（白／黃／綠／藍／黑帶，依累積計入分鐘 100／500／1500／4000，14 天不坐降一級、回來即恢復）、22 枚徽章、每日試煉（依日期固定）、每日語錄（公版古文＋道場短句）、道場配色依段位解鎖、洞察解鎖（分心 10 次→時刻分布，30 次→黃金時段）、招式實驗（下回想試一招→下一坐問有沒有效→累積「我的招式」）、自訂分心原因、成果卡（canvas 1080² 走分享／下載）與無後端挑戰連結（成績編進網址 `#c=`，對方接受後同時長比分心次數）、入門三句＋道號／使命。

## 開發
```bash
python3 -m http.server 8765   # 開 http://localhost:8765
```
改 js/css 後記得升 `sw.js` 的 `VERSION`。

## 部署
靜態站，根目錄直接推 Cloudflare Pages / Netlify。
