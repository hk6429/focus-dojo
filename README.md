# 專注道場 focus-dojo

個人專注力訓練 PWA。純前端、免帳號、資料存 localStorage，可加到手機主畫面離線使用。

## 功能
- **專注計時**：設任務與時長（15/25/45/60 或自訂），計時中一鍵記錄分心原因（手機／雜念／他人／其他），切離畫面自動記為分心；完成或提早結束皆存檔。
- **呼吸熱身**：4-7-8 或方塊呼吸，1／3／5 分鐘，圓圈隨階段縮放。
- **注意力小遊戲**：舒爾特方格（1→25 計時）、Stroop 色字（20 題，正確率＋反應時間）。
- **紀錄**：連續天數（完成或 ≥5 分鐘即算）、今日／30 天專注分鐘、每小時分心率週趨勢、分心原因排行、遊戲進步、最近紀錄；JSON 匯出／匯入。

## 開發
```bash
python3 -m http.server 8765   # 開 http://localhost:8765
```
改 js/css 後記得升 `sw.js` 的 `VERSION`。

## 部署
靜態站，根目錄直接推 Cloudflare Pages / Netlify。
